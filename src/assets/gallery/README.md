# Clinic photo gallery

Drop real clinic photos here (JPG, PNG or WebP). They appear automatically
on the home page in the "Our Office & Smiles" section after the next build.

- Name each file by what it shows — the name becomes the image description
  for blind visitors: `reception-area.jpg`, `treatment-room.jpg`.
- Recommended size: about 1200 px wide, under 300 KB each
  (compress free at https://squoosh.app).
- Patient photos / before-and-after: only with the patient's signed written
  authorization (HIPAA).
